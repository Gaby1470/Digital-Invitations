Place your site images in this folder using these exact filenames:

- favicon.png            Browser tab icon
- apple-touch-icon.png   iPhone/iPad home screen icon
- share-image.jpg        Social share preview image

Recommended sizes:
- favicon.png: 32x32 or 48x48
- apple-touch-icon.png: 180x180
- share-image.jpg: 1200x630
